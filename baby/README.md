# Трекер малыша (`/baby/`)

PWA-трекер для одной семьи: сон и бодрствование, кормления, подгузники, прогулки,
статистика за неделю, календарь записей к врачу, белый шум и кнопка SOS.

Живёт на GitHub Pages: <https://kustos.ru/baby/>

## Файлы

| Файл | Назначение |
|---|---|
| `index.html` | Разметка приложения (~9,5 КБ) |
| `styles.css` | Все стили и темы |
| `app.js` | Логика: таймеры, лента, офлайн-очередь, статистика, календарь |
| `chart.js` | Chart.js, вендорный бандл; грузится **только** при открытии статистики |
| `sw.js` | Service worker: кэш оболочки, офлайн-навигация, web push |
| `manifest.json` | PWA-манифест: иконки, `scope`, `start_url` |
| `icons/` | PNG-иконки 180/192/512 и maskable |
| `sounds/` | Белый шум, дождь, «утроба», сердце — моно 48 кбит/с, всего 5,9 МБ |

## API

Бэкенд — FastAPI на Amvera, отдельный репозиторий `amvera-api` (`api.py`).
База — SQLite в `/data/baby_data.db`.

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/api/baby/events/today` | события за последние 24 часа |
| GET | `/api/baby/events/week` | события за неделю (для графиков) |
| GET | `/api/baby/events/history?days=14` | события за N дней (лента истории) |
| POST | `/api/baby/events/quick` | быстрая запись (кормление, подгузник) |
| POST | `/api/baby/events/start` | начать сон / бодрствование / прогулку |
| POST | `/api/baby/events/{id}/stop` | завершить событие |
| DELETE | `/api/baby/events/{id}` | удалить запись |
| GET/POST/DELETE | `/api/baby/appointments` | календарь записей к врачу |
| POST | `/api/baby/sos` | push-уведомление второму родителю |

## Авторизация

По умолчанию API **открыт** — так было исторически. Защита включается одной
переменной окружения в панели Amvera:

```
BABY_API_TOKEN=<длинная случайная строка>
```

После этого все `/api/baby/*` требуют заголовок `X-Api-Token` или `?token=`.
Исключения: `OPTIONS` (CORS preflight) и `/api/baby/vapid-public-key`.

**Как включить на устройствах** (один раз на каждое):

1. Задать `BABY_API_TOKEN` в переменных окружения Amvera и перезапустить приложение.
2. Открыть на телефоне ссылку со токеном:
   `https://kustos.ru/baby/?token=<значение>`
3. Приложение сохранит токен в `localStorage` и уберёт его из адресной строки.
   Дальше ссылкой можно пользоваться без параметра.

Если токен потерян — просто поменяйте `BABY_API_TOKEN` и повторите шаг 2.
Если переменную удалить, API снова станет открытым.

## Офлайн

- События кэшируются в `localStorage` (`baby_events_cache_v1`) при каждом успешном
  запросе; при отсутствии сети лента показывает последние сохранённые данные.
- Записи кормлений и подгузников при сбое сети попадают в очередь
  (`baby_queue_v1`) и отправляются автоматически при появлении связи.
- В шапке появляется индикатор `📴 офлайн` / `⏳ ждут отправки: N`.
- Кнопка **Экспорт данных** в календаре выгружает всё известное в JSON.

## Локальный запуск

```bash
cd antispam-landing
python3 -m http.server 8080
# открыть http://localhost:8080/baby/
```

Service worker и `manifest` требуют HTTPS или `localhost`.

## Деплой

GitHub Pages собирает ветку `main` автоматически:

```bash
git add baby && git commit -m "..." && git push origin main
```

Изменения появляются на сайте через ~20–60 секунд.

## Тесты

Рендер ленты проверяется без браузера — мини-DOM на Node.js, без зависимостей:

```bash
cd baby
node tests/render.test.js
```

Тест подставляет синтетические события и проверяет: лента отрисовалась,
события сгруппированы по дням, сегодняшняя секция раскрыта, вчерашняя свёрнута,
ошибок в консоли нет. Проверено, что он падает (8 провалов), если вернуть
историческую ошибку `grouped[dateStr]` вместо `grouped[key]`.

## Известные ограничения

- Все данные лежат в SQLite на Amvera; отдельного экспорта с сервера нет —
  бэкап делается кнопкой экспорта в приложении.
- Лента показывает 14 дней; глубже — по мере роста базы нужен пагинатор.
- Разметка собирается через `innerHTML` (данные экранируются функцией `esc`).
